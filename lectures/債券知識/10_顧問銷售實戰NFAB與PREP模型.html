A

NFAB模型：需求先於特徵，利益必須是客戶自己認出來的

原文 p.119　Position Products Using Needs, Features, Advantages and Benefits

原文點出一個常見的銷售陷阱：「我們常常直接推銷產品特徵，把它們當成優勢來解釋——但特徵只有在滿足客戶需求的前提下，才算得上優勢。」NFAB模型把順序拉回正確的因果關係：

Needs（需求） → Features（特徵） → Advantages（優勢） → Benefits（利益） 1. 先釐清並排序客戶的需求 2. 只挑「對這個需求有幫助」的產品特徵來說明 3. 把特徵翻譯成優勢——這個特徵能做到什麼 4. 讓客戶自己認出：這個優勢，如何對應到他原本講的那個需求（這才是「利益」）
套用整個系列，示範一次NFAB

需求：客戶（第9堂C段的九大構面評估後）確認是一位風險承受度中等、5年內有明確子女教育金支出需求的退休人士。
特徵：一檔BBB評等、5年期到期、票息4.5%的優先無擔保公司債（第4堂A段）。
優勢：固定的到期日與票息，現金流可預測（第1堂B段）；BBB是投資等級最後一級，違約率歷史統計仍相對溫和（第4堂C段5年期BBB違約率1.58%）。
利益：「這檔債券5年後到期，剛好對應您孩子上大學的時間點，票息也能提供您這段期間穩定的現金流——這正是您說的，希望有一筆『確定會在需要的時候到位』的錢。」——利益句必須讓客戶自己聽出「這就是我要的」，而不是顧問單方面宣稱「這是好產品」。

原文 p.119Position Products Using NFAB
原文說明NFAB模型的邏輯順序，強調特徵必須先確認能滿足客戶需求，才能被稱為優勢，並由客戶自己辨識出利益。
B

PREP模型：一段有說服力陳述的四個節拍

原文 p.121　PREP Model

PREP是組織「一段話」的結構，比NFAB更適合用在簡短的電梯陳述或開場：

Point（要點） → 先講結論 Reason（理由） → 為什麼這個結論成立 Example（範例） → 具體證據支撐理由 Point（要點） → 重申結論，首尾呼應
原文範例（ESG／企業定位陳述）

要點：「SCB是地球上最綠色的大型銀行。」
理由：「我們的策略與執行計畫，反映了『Here for good』的使命。」
範例：「我們已經有經過驗證的2050淨零排放計畫，並在COP26上被認可為永續金融的領導者。」
要點：「這就是為什麼我們相信自己是地球上最綠色的大型銀行。」

套用第8堂案例，示範一次債券情境的PREP

要點：「CoCo／AT1債券的票息雖然誘人，但它承擔的是一種跟一般公司債完全不同的風險。」
理由：「因為它的減記可能來自監管機關的裁量，不需要走傳統的違約認定流程，求償順位保護也可能被繞過。」
範例：「2023年瑞士信貸事件裡，160億瑞士法郎的AT1被直接減記到零，而同一時間股東反而拿到了收購對價——這在傳統求償順位邏輯下是不會發生的結果（第8堂D段）。」
要點：「所以評估CoCo／AT1，不能只看票息數字，一定要把監管裁量風險也算進整體的風險預算。」

原文列出六道關於到期日、配息頻率、應計利息、發行規模、拍賣結果的檢測題目，解答見附錄p.123。
1. 這檔債券何時到期？
2027年12月31日（原文解答）——對應終端機欄位 Maturity Date。
2. 每年配息幾次？
S/A，semi-annual，一年配息兩次（第1堂B段的標準債券配息頻率）。
3. 配息月份是哪幾個月？
6月30日與12月31日。
4. 若持有USD 100,000名目本金，下一期票息是多少？
USD 100,000 × 3.875% ÷ 2 = USD 1,937.50
下一期實際配息日期，取決於「今天」是上半年還是下半年（6月或12月）——這正是第1堂C段「應計利息」概念的實際應用場景：如果你在配息日之間買進，賣方會跟你收取這段期間已經累積、但尚未發放的應計利息。
5. 這次發行的總金額是多少？
USD 43,000 百萬 = 430億美元
原文p.123的解答文字寫「USD 43,000,000」，對照終端機欄位「Amount Issued 43000 (MM)」，正確的完整金額應為430億美元（43,000百萬）——這裡以終端機原始欄位為準。
6. 這次拍賣的最低承標價格是多少？
原文解答：101 − 0.1275 = 100.8725
這是原文附錄（p.123）直接給出的解答，反映的是這檔公債2023年1月初次拍賣時的最低承標價格，與終端機截圖上顯示的「目前報價」101-12¾（次級市場即時價格）是兩個不同時間點、不同性質的數字——前者是初級市場拍賣結果，後者是之後某個交易日的次級市場報價（第1堂E段）。本講義未取得原始拍賣公告文件逐位覆核此計算，僅忠實引用原文解答。
這道題其實測驗了整個第1堂

到期日、票息頻率、應計利息計算、發行規模、拍賣機制——這六題涵蓋了第1堂B、C段幾乎全部的字彙。如果這六題你都能不看解答直接答對，代表整個系列最基礎的地基已經打穩了。

十堂課總覽：公式與框架速查表

本講義系列總結
堂數核心公式／框架
第1堂Price = C×[(1−(1+y)⁻ⁿ)/y] + FV×(1+y)⁻ⁿ；交割金額 = 本金 + 應計利息 + 費用
第2堂ΔPrice/Price ≈ −存續期間 × Δy；殖利率曲線倒掛 = 短天期利率 > 長天期利率
第3堂預期損失 = 違約機率(PD) × 違約損失率(LGD)；資本結構：股權→混合證券→次順位債→優先無擔保債
第4堂BBB-/Baa3 = 投資級與高收益級分水嶺；評等對照Moody's/S&P/Fitch
第5堂YTW = min(YTM, YTC)；轉換價格 = 面額 ÷ 轉換比率
第6堂浮動利率票息 = 參考利率 + 信用加碼；騎乘殖利率曲線報酬計算
第7堂CET1 = 普通股股東權益+保留盈餘−扣除項；CET1比率 = CET1 ÷ RWA
第8堂CDS隱含違約機率 ≈ CDS利差 ÷ (1−回收率)；AT1監管裁量減記可繞過傳統求償順位
第9堂存續期間匹配（資產存續期間 ≈ 負債存續期間）；客戶適合度九大構面
第10堂NFAB：需求→特徵→優勢→利益；PREP：要點-理由-範例-要點

完課總結

  • 十堂課從「一張債券的三個要素」出發，一路建到「一次真實的監管裁量減記事件」——技術深度是疊加式的，每一堂都在用前面的字彙。
  • NFAB與PREP不是話術技巧，而是把前九堂的技術判斷（這檔債券的風險在哪、適合誰）誠實地轉譯給客戶聽懂的紀律。
  • 期末複習題證明了一件事：讀懂一張真實的債券終端機截圖，不需要死背，只需要把「到期日、票息、應計利息、殖利率、評等、求償順位」這組字彙內化成直覺反應。
